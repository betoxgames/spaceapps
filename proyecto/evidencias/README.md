# Evidencias

Guarda capturas y registros seleccionados que respalden una versión o una decisión. Las capturas automáticas se generan en `test-results/`; incorpora aquí las que ayuden a explicar lo verificado.

Para cada evidencia registra:

- Fecha y responsable.
- Versión/tag o commit exacto.
- Flujo o criterio comprobado y resultado observado.
- Archivo o enlace al material y limitaciones de la prueba.

Ejemplo: `2026-11-15_v1.0.0_prueba-offline.png`. Una captura no acredita una versión posterior sin volver a comprobarla.
