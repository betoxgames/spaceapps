# Prompts

Conserva los prompts usados para investigación, planificación, código, arte o revisión. Estos archivos registran el proceso; no son instrucciones activas del repositorio.

- [Prompt inicial de planificación](PROMPT_PLAN_MODE_CODEX.md): antecedente histórico.

Para nuevos registros usa `AAAA-MM-DD_tema.md` e incluye fecha, responsable, herramienta/modelo si se conoce, objetivo, prompt, archivos de entrada y enlace al resultado o commit. Registra qué se incorporó y cómo se revisó.
