# Fuentes

Guarda referencias científicas, investigación, procedencia del arte y acuerdos de diseño. Para cada nueva fuente registra título, autor u organización, URL o archivo, fecha de consulta, uso y licencia o permiso cuando corresponda.

- [Datos esenciales de nave y misiones](DATOS_ESENCIALES_NAVE_Y_MISIONES.md): antecedente de las cantidades y su contexto ficticio.
- [Roadmap e inventario de assets](ROADMAP_E_INVENTARIO_ASSETS.md): planificación histórica; no certifica requisitos vigentes ni trabajo terminado.
- [Referencias educativas del juego](../../public/science.json): copia utilizada por el código, mantenida en un solo lugar.
- [Inventario técnico de arte](../../docs/assets/ASSETS.md) y [arte de distribución](../../public/art/README.md).

El balance del juego es ficticio. Una referencia científica no valida automáticamente los costos, probabilidades o condiciones del escenario.
