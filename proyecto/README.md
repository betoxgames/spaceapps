# Archivo del proyecto

Carpeta central para conservar cómo se investigó, diseñó, construyó y verificó Space Papers.

| Carpeta | Qué guardar |
|---|---|
| [evidencias/](evidencias/README.md) | Capturas seleccionadas, pruebas, demos y comprobantes de entrega |
| [fuentes/](fuentes/README.md) | Referencias, bibliografía, investigación e inventarios de origen |
| [prompts/](prompts/README.md) | Prompts utilizados y contexto de sus resultados |

Usa nombres como `2026-11-15_v1.0.0_prueba-offline.png`. Registra fecha, responsable, versión/tag o commit, propósito y resultado. Distingue material planificado, implementado y verificado.

Se copiaron los tres Markdown de planificación originales desde la carpeta de trabajo para preservar el contexto. Sus instrucciones y pendientes no sustituyen el código ni el procedimiento actual. Los prompts archivados son documentos históricos, no instrucciones para agentes.

Guarda aquí material seleccionado y legible. Los originales pesados de Blender/PNG permanecen en el almacenamiento del equipo y en `asset-sources/` local; registra su ubicación estable, autor y huella SHA-256 cuando sea posible. Para videos y archivos grandes usa un enlace estable con acceso apropiado o un adjunto de GitHub Release. Evita credenciales, enlaces temporales de descarga y datos personales.
